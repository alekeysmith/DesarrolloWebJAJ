1. Información general

Contenido del taller

  • Estructura básica y semántica de HTML5
  • Hojas de estilo externas (CSS)
  • Maquetación usando Flexbox y CSS Grid
  • Controles de formularios y validación

Requisitos previos (en orden)

  1. Aprobar Programación I
  2. Tener un editor de texto instalado
  3. Laboratorio 1 al día
  4. Pagar la matrícula

Glosario básico

HTML
Lenguaje que da la estructura a la página de internet.
CSS
Da el estilo, colores y formato visual a la página.
Responsive
Diseño que se adapta para verse bien en celulares y computadoras.
